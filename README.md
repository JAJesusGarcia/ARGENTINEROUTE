# 🌎 About

**Argentine Route** is a premium tourism platform designed to showcase the best destinations throughout Argentina.

The project combines cinematic visuals, high-quality photography, immersive storytelling and modern web technologies to provide a luxury travel experience.

The objective is to become one of the most complete tourism platforms dedicated exclusively to Argentina.

# ⚙ Installation

Clone repository

```bash
git clone https://github.com/JAJesusGarcia/ARGENTINEROUTE.git
```

Install dependencies

```bash
pnpm install
```

Run development server

```bash
pnpm dev
```

Open

```
http://localhost:3000
```

---

# 🏗 Production Build

```bash
pnpm build
```

Run production

```bash
pnpm start
```

---

# ☁ Media Storage

All project assets are hosted in **Cloudinary**.

The repository only stores source code.

Images and videos are automatically served from Cloudinary using helper functions.

---

# 🚀 Deployment

Production deployment is handled by **Vercel**.

Workflow

```
GitHub
↓

main branch
↓

Vercel

↓

Production
```

Every push to **main** automatically deploys a new production version.

# 🌿 Git Workflow

Main branch

```
main
```

Development branches

```

```

Never develop directly on **main**.
